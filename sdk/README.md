# @rndm/dime-sdk

TypeScript client for DIME, the 1000× house for BTC and Nvidia: quotes, orders, closes, gasless session keys, API keys and live
streams. Peer dependency: `viem`. Node 22+ or any modern browser.

```ts
const dime = new DimeClient({ api: "https://api-dime.rndm.io", apiKey });
const order = await dime.open({ account, signer: sessionKey, side: "LONG", margin: 5, leverage: 1000 }); // BTC-USD
const nvda = await dime.open({ account, signer: sessionKey, market: "NVDA-USD", side: "SHORT", margin: 5, leverage: 500 });
```

Full guide: [docs/DEVELOPERS.md](../docs/DEVELOPERS.md). `src/abi.ts` is generated by `scripts/export-abis.mjs`.
